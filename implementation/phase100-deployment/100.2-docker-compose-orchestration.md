# Step 100.2: Docker Compose Orchestration

## Prompt

```
Implement Docker Compose orchestration for multi-service deployment with these requirements:
1. Create main docker-compose.yml with all service definitions
2. Implement service dependencies and startup order
3. Configure internal networking with service isolation
4. Set up volume management for data persistence
5. Create environment-specific compose overrides
6. Implement service scaling configurations
7. Configure resource limits and reservations
8. Set up logging and log rotation
9. Create development and production profiles

Output should include docker-compose configurations, network definitions, volume strategies, and orchestration best practices.
```

## Implementation Guidelines

### Service Orchestration

#### Service Dependencies
- Define explicit service dependencies
- Implement health-based startup ordering
- Configure restart policies
- Design graceful shutdown procedures
- Create initialization sequences

#### Network Configuration
- Internal service network creation
- Service discovery configuration
- Port exposure management
- Network isolation strategies
- DNS configuration for services

#### Volume Management
- Named volumes for data persistence
- Bind mounts for development
- Volume backup strategies
- Permission management
- Data migration procedures

### Environment Management

#### Development Configuration
- Hot reload volume mounts
- Exposed debugging ports
- Extended logging output
- Development tool integration
- Fast rebuild strategies

#### Production Configuration
- Optimized resource allocation
- Security-hardened settings
- Production logging levels
- Monitoring integration
- Backup automation

### Scaling and Performance

#### Service Scaling
- Horizontal scaling configuration
- Load balancer integration
- Session affinity settings
- Resource pool management
- Auto-scaling policies

#### Resource Management
- Memory limits and reservations
- CPU allocation strategies
- Disk I/O limitations
- Network bandwidth control
- Swap configuration

### Monitoring and Logging

#### Logging Strategy
- Centralized log collection
- Log driver configuration
- Retention policies
- Log rotation settings
- Structured logging format

#### Health Monitoring
- Service health checks
- Dependency monitoring
- Resource usage tracking
- Alert configuration
- Dashboard integration
